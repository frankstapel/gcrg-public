y# Data Format and Structure

This project analyzes climbing routes for training boards. To use this code, provide your route data in one of the accepted formats below.

## Overview

The project expects route data in the `/data/` directory. You will need to provide route data and optionally a manual hold difficulty classification.

## Directory Structure

```
data/
├── routes_input/      # Your route data files (place data here)
├── hold_scores/       # Hold difficulty classifications
├── routes/            # Processed route dataframes
├── move_scores/       # Processed move scoring data
├── sequences/         # Route sequence data
├── models/            # Trained machine learning models (generated by code)
└── sequencer/         # Sequencing working files
```

## Data Formats

### 1. Route Input Data (`data/routes_input/`)

The project expects raw route data in one of two formats:

#### Option A: JSON Format
- **File**: `{YEAR}_{BOARD}.json`
- **Required columns**:
  - `Grade`: Climbing grade (e.g., "5A", "5A+", "5B", etc.)
  - `Moves`: List of hold coordinates as letter-number pairs (e.g., `["A1", "B2", "C3"]`)
- **Example**:
```json
[
  {
    "Grade": "5B",
    "Moves": ["A1", "B2", "C3", "D4"]
  },
  {
    "Grade": "5B+",
    "Moves": ["A2", "C3", "E4", "F5"]
  }
]
```

#### Option B: Pickle Format (dict of routes)
- **File**: `{YEAR}_{BOARD}.pkl`
- **Format**: Dictionary with route IDs as keys and route dictionaries as values
- **Required fields per route**:
  - `grade`: Climbing grade (string)
  - `start`: List of starting hold coordinates `[[x, y], ...]`
  - `mid`: List of middle hold coordinates `[[x, y], ...]`
  - `end`: List of ending hold coordinates `[[x, y], ...]`
- **Coordinate system**: `[0-10, 0-17]` (columns 0-10, rows 0-17 on standard 4x12 MoonBoard)
- **Example**:
```python
{
  "route_0": {
    "grade": "5B",
    "start": [[0, 0], [10, 0]],
    "mid": [[5, 8], [5, 10]],
    "end": [[3, 16], [7, 16]]
  }
}
```

### 2. Hold Difficulty Classification (`data/hold_scores/`)

This file contains the classification of which holds are difficult vs. easy. It's used to score moves.

#### Manual Classification (Optional)
- **File**: `{YEAR}_{BOARD}_manual.csv`
- **Format**: CSV with semicolon separator, comma as decimal
- **Columns**:
  - `x`: Column letter (A-K for MoonBoard)
  - `y`: Row number (1-18 for MoonBoard)
  - Hold difficulty classification fields (optional)
- **Example**:
```csv
x;y;difficulty
A;1;easy
A;2;medium
B;5;hard
```

#### Generated Hold Scores (Auto-generated)
- **File**: `{YEAR}_{BOARD}_hold_scores.pkl`
- This is generated by running `classification/hold_scores.py`
- Contains a pandas DataFrame with hold difficulty scores indexed by `(x, y)` coordinate

### 3. Configuration

Edit `settings.py` to specify your data:

```python
YEAR = "2016"      # Your data year
BOARD = "moonboard" # Board type
VERBOSE = True      # Enable debug output
```

## Coordinate System

The MoonBoard uses a grid system:
- **Columns**: 0-10 (represented as A-K in some formats)
- **Rows**: 0-17 (1-indexed as 1-18 in CSV format)

When converting from letter-based coordinates (e.g., "A1") to numeric:
- Letter A-K → 0-10
- Row 1-18 → 0-17 (subtract 1)

## Prepare Your Data

1. **Export your routes** into one of the accepted formats
2. **Place data file** in `data/routes_input/{YEAR}_{BOARD}.[json|pkl]`
3. **(Optional) Create manual hold classification** in `data/hold_scores/{YEAR}_{BOARD}_manual.csv`
4. **Update settings.py** with your YEAR and BOARD values
5. **Run the code** - it will generate:
   - `data/routes/{YEAR}_{BOARD}_routes.pkl` - processed routes
   - `data/hold_scores/{YEAR}_{BOARD}_hold_scores.pkl` - computed hold difficulties
   - `data/move_scores/` - move scoring analysis
   - `data/sequences/` - route sequences

## Grades and Grading Systems

The code supports Font grade conversion to multiple systems:
- **Font**: 4A, 4A+, 4B, 4B+, 4C, ... (MoonBoard standard)
- **Ordinal**: Numeric encoding of grades
- **IRCRA**: International grade scale

Grades are normalized to [0, 1] for model training.

## Expected Data Sizes

- **Small dataset**: 500-1000 routes
- **Medium dataset**: 2000-5000 routes
- **Large dataset**: 5000+ routes

Minimum recommended: 500+ unique routes for reliable statistical analysis.

## Troubleshooting

- **"Could not find data file"**: Check that your data file is in `data/routes_input/` with the correct naming: `{YEAR}_{BOARD}.json` or `.pkl`
- **"Hold [0, 5] not found"**: Remove invalid holds; see coordinate system above
- **Missing manual classification**: The code will work without manual data; it's optional
- **Low route counts after cleaning**: Your data may have many duplicates - check your source data
